# 视图模型：文示二支 × 四叶选择

> 本文是视图系统的唯一设计依据；代码与本文不一致时，先改本文。
> 术语：四叶 = flow / column / slide / present（paper 预留，设计已裁决，见 §5）；
> UI 刻度 =「文 栏│览 示」（paper 落地时为「文 栏 纸│览 示」）。
> flow 的键名刻意避开 page——给 Word 式 A4 分页的「纸面（paper）」叶让位。

## 1. 结构：两支四叶

```
 文（编辑态）                示（展示态）
 muya 进程内                 md2slides iframe
 ┌──────┬───────┐          ┌────────┬─────────┐
  flow  column            slide    present
  全文流 分栏               页览      放映
 └──────┴───────┘          └────────┴─────────┘
 空间轴：连续 → 离散         时间轴：全页可见 → 一次一页
 可编辑                      只读（真分页 · 真主题）
```

- **文示的分界 = 引擎边界 = 可编辑性边界**（"借进程不借 DOM"的空间化表达；
  跨组分屏时，分割条就画在引擎边界上）；
- 每支内部一根粒度轴，两轴**正交**——不存在跨支的单一粒度序；
- **表 / 图 / 本**是顶级正交视图（两个内容透镜 + CodeMirror 源码），不进这棵树。

**预留叶：paper（纸面，未实现）**——Word 式 A4 分页的编辑形态。落地时它是
**文支第三叶**（可编辑、按物理页切），树变为：

```
 文（编辑态）                          示（展示态）
 ┌─────┬──────┬──────┐              ┌──────┬────────┐
  flow  column  paper              slide    present
  全文流 分栏    纸面(A4)            页览      放映
 └─────┴──────┴──────┘              └──────┴────────┘
```

- `flow` 键名正是为它让位（page 会与物理页撞名）；paper 的页边界是物理的
  （A4 高度），度量来源已裁决：muya 直测（全套裁决见 §5），
  "借进程不借 DOM"的边界原则不变；
- 「页览」的"页"届时自然消歧：页 = 物理页，无论幻灯片还是 A4。

## 2. 选择模型

- 四叶**常驻平铺**在切换器上（刻度「文 栏 │ 览 示」，支间一道分隔线提示两根轴）；
- **配置选择式**：点一下选中、再点一下取消，搭配由用户自定，**至多两叶**：
  - 1 叶 → 该视图全屏；
  - 2 叶 → 分屏，左右按按钮序（flow < column < slide < present）——
    文左示右、细左粗右由顺序自动成立；
  - 已两叶时第三叶点不动（先摘一片才能换）；最后一片不可摘（不可选到零）；
- 表/图/本与四叶互斥：选中顶级视图时叶选择挂起不丢，切回即恢复；
- column 叶只对真有 `begin` 标记的文档显示；全屏 column 在标记消失时回退 flow
  （分屏中的 column 投影不回退——投影为空无害）；
- 选择与分割比例持久化；旧持久化形状（mainView/subView 二级结构）自动迁移。

## 3. 分屏交互

- 中间**分割条可拖**，比例记住（0.2–0.8）；**分屏时页宽滑块失效收起**
  （宽度控制被分割条吸收）；
- 单视图滑块回归：flow/表/图 = 内容列宽（页宽滑块）；present 无；页览 = 页缩放（声明未接线）；paper = 页缩放（同族待接线，见 §5）；
- (览, 示) 两叶皆只读 = 预演/导航模式（PPT 缩略图 + 大页的姿态）；
- 键盘归属：分屏时编辑器保焦点；deck 只吃鼠标/触屏；deck 聚焦时 Esc 关自己。

## 4. 页览叶（slide）

- md2slides 渲染的**全部真实物理页堆叠**：真分页、真主题、（续）页重复表头；
  放大即原尺寸，非截图缩略图；
- 刻度名「览」：说动作与视态（全部页一眼尽收），不押内容形态——物理页将来是
  幻灯片还是 Word 式 A4 分页都成立；
- **溢出提示**：物理分页永不产出溢出页（装不下即切（续）页），"溢出"的诚实
  语义 = **一个逻辑页被切成 N 张物理页**——首页挂「N页」徽章、（续）页虚线
  描边，工具条报「N 页 · M 页溢出」。数据在 deck 手中（（续）标记），deck 侧
  打标，不需要 muya 侧配合。

## 5. 纸面叶（paper）设计裁决（2026-11-01，未实现）

> 概念对照（参照系 Word）：页面视图 = paper 叶；页面设置（纸型/边距）=
> frontmatter 文档级声明；分页符（Ctrl+Enter）= HTML 注释标记；打印预览 =
> 既有打印链（printService → printToPDF），不新造。`---` 在纸面文档保持
> 水平线语义——幻灯片的逻辑分页语法不搬进来。

- **度量来源 = muya 直测**，不借渲染器实测：
  - 单一版式真源：打印链本就用 muya 的 exportStyle.css 渲染；paper 屏显
    注入与 `@media print` 同源的版式基（字号/行高/页宽以物理单位出变量），
    编辑所见 = 打印所得——Word 页面视图的全部价值主张；
  - 对称性：§4 的哲学是"数据在 deck 手中，deck 侧打标"；paper 是文支叶，
    页界是 muya 进程内自己的事，量自己的 DOM 在"借进程不借 DOM"边界之内；
  - 复用算法不复用进程：md2slides `overflow.js` 的分配核心（搬块/切块/
    （续）页/表头重复）抽成无 DOM 依赖的纯函数包——块高序列 + 页高 +
    策略封闭集 → 分配 + diag——双端各自量 DOM 各自调用（顺 IR_v3 A2/A3
    语义与分页解耦的方向）；
- **实现姿态 = 连续流 + 缝叠加**：muya 保持单一连续 block 流（不把 block
  分散进多纸容器），容器宽 = A4 内容宽（794px@96dpi 减边距）；"纸"是背景
  层，分页线与页码是测量结果的绝对定位投影——Word 页面视图本就是连续纸堆
  滚动，不是真切片；
- **切页策略分级**：v1 块级 keep-together（缝只落块边界，跨缝难题不存在）；
  超整页块降级 = 穿缝（缝线虚线让过），**不缩字号**（Typora"段落过高且缩
  至字号下限"之坑在设计层堵死）；v2 段落跨页切行（widow/orphan ≥ 2）、
  表格行切 + （续）页表头（算法包移植）；
- **分页符 = HTML 注释标记族**：`<!-- pagebreak -->`，与 column 的
  `<!-- begin/split/end -->` 同族——不占 `---`、纯文本可移植；注释不渲染
  **内容物**（区别于 `---` 的水平线），但按族惯例渲染编辑态徽标（⤓ 分页
  符，与 mdcols 徽标同款 affordance，栏视图随族隐藏）；屏测读徽标作强制缝
  （本页无正文时镜像 Chromium 语义忽略——连续/文首分页符不产空白页），打印
  链由 exportHtml 把注释行换成零高标记 div 走 `break-after: page`；纸型/
  边距归 frontmatter（`paper: A4|letter`，M3 屏侧生效，打印侧默认 A4、
  导出对话框仍是打印纸型的用户入口）；
- **交互入位**：刻度「文 栏 纸│览 示」，按钮序 flow < column < paper <
  slide < present（文左示右自动成立）；paper 常显（任何文档都有页面视图，
  不学 column 的"有标记才显示"）；**paper 只与文支配对**——纸×览/示在 v1
  语义不成立（览对 A4 文档 v1 不做、纸对幻灯片文档无意义），与示支叶相点
  即单选替换，持久化中的非法对净化为单片；单视图滑块 = 页缩放（A4 常超
  窗宽，缩放是刚需，与页览 slide-zoom 同族，均待接线）；
- **「览」对 A4 文档**：v1 不做（paper 自身已按页可见，页览冗余）；将来走
  paper-pane（marktext 链只读堆叠投影，同 leafProjection 第二实例思想），
  不走 deck-pane——md2slides 只服务幻灯片形态（IR_v3 R6 回写口 0 本就不
  管常规编辑器版式），不把 A4 版式塞给它；
- **落地切片**：M0 `Leaf` 加 `'paper'` + 刻度/按钮序/持久化（新增枚举值，
  旧持久化无需迁移）→ M1 A4 版式容器 + 版式基与打印同源 → M2 测量循环 +
  缝/页码叠加 + keep-together → M3 分页符 + frontmatter 纸型 → M4 块内
  切分（算法包双端共用 + 快照回归）。**硬验收 = 屏显页数 = printToPDF
  页数**（M1 起测）；此验收一倒，度量来源裁决重审。
