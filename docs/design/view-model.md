# 视图模型：二组 × 五叶选择

> 本文是视图系统的唯一设计依据；代码与本文不一致时，先改本文。
> 术语：五叶 = flow / column / page / slide / present。
> 持久化只认现行形状：未知 key 与旧形状一律落默认（`flow`），不做迁移。

**UI 刻度**：「文 栏│页 览 映」（栏随文档有无 `begin` 标记显隐，分隔线
提示二组）。

## 1. 结构：二组五叶

```
 编辑组（写作姿态，连续块流）      展示组（成页姿态）
 muya 进程内                      页 = muya 进程内；览/映 = md2slides iframe
 ┌───────┬───────┐               ┌─────────┬──────┬──────┐
  文      栏                       页        览     映
  全文流  分栏                     物理纸    页览   放映
 └───────┴───────┘               └─────────┴──────┴──────┘
   不切    横切                      滚动      全景   时序
```

- **组判据 = 姿态，不是可编辑性**：编辑组 = 你在写文本（页界至多是提示）；
  展示组 = 你在看页。刻度回答"我在看什么"——可编辑性由 §2 的编辑面不变量
  统一立法（只有文/本可编辑），不押在叶子上；
- **引擎边界不与分隔线重合**：页在 muya 进程内（只读真分片投影），览/映在
  md2slides iframe（只读）；栏在编辑组但同样只读（透镜态活引擎，§6）。
  跨引擎分屏（文/栏 × 览/映）时分割条恰在引擎边界上；组内或页参与的分屏，
  分割条只是 UI 分隔；
- 编辑组一根切法规轴（不切→横切），展示组一根浏览轴（滚动→全景→时序），
  两轴**正交**——不存在跨组的单一粒度序；
- **表 / 图 / 码**是顶级内容透镜（同一 muya 活引擎的只读形态，三透镜齐活），
  **图** = 代码型图表块总览（mermaid/echarts/plantuml 等围栏图表，
  `figure.mu-diagram-block`；行内图片不进图——muya 无 image 块态，2026-11-08
  评估后放弃：晋升时机无回车锚点、图片工具生态全 key 在行内选中态上），
  **本**是 CodeMirror 源码视图——四者皆顶级正交视图，不进这棵树；键名
  `table` / `figure` / `code` / `source`，**`code` 即「码」**（全文代码块总览，
  2026-11-08 起），**`source` 即「本」**（Markdown 源码）。底部代码执行窗是
  工具窗（非视图）：入口 = 文/码面代码块围栏的 ▶ 运行按钮、码透镜单击块定位，
  仅单视图可用（判据 `isCodeRunSurface` = 文独占 ∨ 码透镜独占）；面板右上角
  自带关闭钮，切换器不再承载执行窗开关。可编辑与否见 §2。

**页（page）**——A4/Letter 纸面预览（frontmatter 声明）：内容按真分片装进
一张张固定纸卡，页与页有真间隙，只读。度量来源 = muya 直测（§5）；
「页览」的"页"自然消歧：页 = 物理页，无论幻灯片还是 A4。

## 2. 选择模型

- **五叶平铺**在切换器上（刻度「文 栏│页 览 映」，分隔线提示二组）；栏格随文档有无 `begin` 标记显隐；
- **编辑面不变量：一文一编辑面，多览只读**（§6）——编辑面 = 文（muya 活引擎）或本（CodeMirror 源码态）；其余一律只读：各叶（`column`/`page`/`slide`/`present`）、顶级视图表/图/码、底部执行窗——分屏右 pane 是只读投影（leafProjection 只读第二实例等），`column` 全屏/分屏左叶与表/码是活引擎只读态（§6）。只读面上不就地编辑，想编辑即跳转到文/本的相应处（§6.3）。
  **全屏页叶的可见面 = 只读真分片投影**（paperProjection），活引擎以
  display:none 留任「隐藏服务后端」——bus 导出/TOC 依赖 editor.vue 挂载，
  收起不占位（导出走序列化，不需要布局）；
- **配置选择式**：点一下选中、再点一下取消，搭配由用户自定，**至多两叶**：
  - 1 叶 → 该视图全屏；
  - 2 叶 → 分屏，左右按按钮序（flow < column < page < slide < present）
    ——编辑左、展示右（组内同序）、细左粗右由顺序自动成立；
  - **页×览、页×映不配对**（分屏要求两侧对同一文档做一致解释，而
    md2slides 只服务幻灯片形态——览不服务 A4 文档、页对幻灯片文档给不出
    幻灯片语义；全屏单叶不受此限），与它们相点即单选替换，持久化中的
    非法对净化为单片；(文, 页)、(栏, 页) 的右叶 = 真分片投影
    （paperProjection）；
  - 已两叶时第三叶点不动（先摘一片才能换）；最后一片不可摘（不可选到零）；
- 表/图/码/本与五叶互斥：选中顶级视图时叶选择挂起不丢，切回即恢复；
- column 叶只对真有 `begin` 标记的文档显示；全屏 column 在标记消失时回退 flow
  （分屏中的 column 投影不回退——投影为空无害）；
- 选择与分割比例持久化；只认现行形状，未知 key / 旧形状一律落默认
  （`flow`），不做迁移。唯一例外（2026-11-08）：本/码键名互换（本
  `code`→`source`，码启用 `code`），持久 blob 加 `v: 2`——无 `v` 的旧数据
  中 `topView: 'code'` 一次性归位为 `'source'`，防旧「本」静默变成码透镜。

## 3. 分屏交互

- 中间**分割条可拖**，比例记住（0.2–0.8）；**分屏时页宽滑块失效收起**
  （宽度控制被分割条吸收）；
- 单视图滑块回归：文/表/图/码 = 内容列宽（页宽滑块）；present 无；览 = 页缩放（声明未接线）；页 = 页缩放（版式基钉死纸面宽度，A4 常超窗宽，缩放是刚需，待接线，见 §5）；
- (览, 映) 两叶皆只读 = 预演/导航模式（缩略图墙 + 大页放映的姿态）；
- 键盘归属：分屏时编辑器保焦点；deck 只吃鼠标/触屏；deck 聚焦时 Esc 关自己。

## 4. 览叶（slide）

- md2slides 渲染的**全部真实物理页堆叠**：真分页、真主题、（续）页重复表头；
  放大即原尺寸，非截图缩略图；
- 刻度名「览」：说动作与视态（全部页一眼尽收），不押内容形态——物理页将来是
  幻灯片还是 A4 分页都成立；
- **溢出提示**：物理分页永不产出溢出页（装不下即切（续）页；超高媒体原位
  等比缩放），"溢出"的诚实语义 = **一个逻辑页被切成 N 张物理页**——首页
  挂「N页」徽章、（续）页虚线
  描边，工具条报「N 页 · M 页溢出」。数据在 deck 手中（（续）标记），deck 侧
  打标，不需要 muya 侧配合。

## 5. 页叶：真分片投影与测量基座

- **度量来源 = muya 直测**：单一版式真源——打印链本就用 muya 的
  exportStyle.css 渲染；屏显注入与 `@media print` 同源的版式基（字号/
  行高/页宽以物理单位出变量），屏显所见 = 打印所得。页是 muya 进程内的
  叶，页界是自己的事，量自己的 DOM 在"借进程不借 DOM"边界之内；
- **决策内核单源**：md2slides `layout-core` 纯函数包（切点算术 +
  `cutLinesFitting` 段落切行 + `countFittingPrefix` 表格行前缀）双端各自
  量 DOM 各自调用——算法共用、进程不共用；
- **页 = 真分片页卡**：只读第二 muya 实例量测 → 行级拟合 → 分片执行器把
  块真分散进页卡：段落 = 裁剪窗对（头窗截行 / 尾窗克隆上移）、表格 = 行
  手术（续表克隆表头）、列表/引用 = 子单元手术（OL 续号）、其余整块搬移；
  卡片即页，页间真间隙。全屏页叶时活引擎 display:none 留任「隐藏服务后
  端」（bus 导出/TOC 依赖其挂载），分屏右叶时直接投影；
- **真分片只能活在只读面**（M4.3b 调研结论，一文多览的理论根基）：
  1. DOM 层重组被分栏史证伪：`editorLayout.ts` 因插入锚点 NotFoundError /
     撤销栈空 / 保存走不通三条硬约束被删（muya `utils/columns/DESIGN.md`）；
  2. 结构进块树要求结构编辑不变：栏成员关系由标记钉死，页成员关系随每次
     键入重排 → json1 op path 不断改写 → 撤销栈失效——OT 寻址的根本冲
     突，非工程量问题；
  3. 分栏结构是导入期标记推导，无 `begin` 标记的文档没有结构可借，而分页
     须对所有文档生效；
  4. 引擎插入锚点与 DOM 1:1 耦合（`Parent.insertBefore` 同时走
     children/domNode/json1 三角），视图层搬块进页容器必打断三角；
- **切页策略 = 行级拟合**：段落跨页切行（widow/orphan ≥ 2）、表格行切 +
  续页克隆表头（表头每页占一份）、代码块 keep-together；超整页块降级 =
  穿缝（整块进首屏页、溢出可见），**不缩字号**。屏侧拟合与 Chromium 原生
  切分逐条等价——打印链同步不设段落/表格的块级 break-inside:avoid，两侧
  同一套切分语义；
- **分页符 = HTML 注释标记族**：`<!-- pagebreak -->`，与栏的
  `<!-- begin/split/end -->` 同族——不占 `---`、纯文本可移植；不渲染内容
  物，编辑态渲染徽标（⤓，栏视图随族隐藏）；屏测读徽标作强制缝（本页无
  正文时忽略——连续/文首分页符不产空白页），打印链由 exportHtml 换成零高
  标记 div 走 `break-after: page`。纸型/边距归 frontmatter
  （`paper: A4|letter`）：屏侧几何随之变，导出对话框默认值取自文档声明
  （未声明保留用户上次选择），屏打两侧默认同纸；
- **「览」不服务 A4 文档**：页自身已按页可见，览走 md2slides（只服务幻灯
  片形态），不把 A4 版式塞给它；配对规则见 §2（页×览/映不配）；
- **页缩放待接线**：版式基钉死纸面宽度，A4 常超窗宽，缩放是刚需；
- **硬验收 = 屏显页数 = printToPDF 页数**（`paper-page-count.spec` 常驻）：
  真分片卡片数与 PDF 页数严格一致；此验收一倒，度量来源裁决重审。

## 6. 一文多览：同步定位（2026-11-07 裁决）

> 立场裁决：放弃「多视图皆可编辑」，sync-design（v2.2）**整体废弃**——
> 不再约束实现，也不作参考；其 §11 所列本文修订项（览/映产生编辑意图、
> 码/表/图入事务等）不执行。本节规则自足成文，无需回查该文档。多标签页
> 已关闭：锚与滚动记忆无 tab 维度，模块级单槽；多窗口各是独立 renderer
> 进程，天然隔离。

目标形态：**一文一编辑面，多览只读**。编辑面 = 文（muya 活引擎）或本
（CodeMirror 源码态）；其余一律只读——叶中的栏（第二实例投影）、页
（真分片投影）、览/映（md2slides iframe），顶级视图中的表、图、码，以及底部
执行窗。同步定位回答三个问题：**跟随**（编辑面在哪，览面跟到哪）、**反向
定位**（览面点了哪，编辑面跳到哪）与**跳转编辑**（在览面想改，跳进编辑
面的哪里）。

**只读面收口**（2026-11-07 裁决：文、本之外一律不可编辑）：栏与表/图/码由活引擎
以透镜承载（栏全屏/分屏左叶、表/图/码顶级视图），进透镜即锁、离开即复原——有效
只读 = 用户只读锁 ∨ 只读透镜（column / table / code / figure），复原按用户锁
取值，不得顺手解开用户自己上的锁。muya 原生支持运行时切换
（`setOptions({ readOnly })`：容器 contenteditable 翻转 + 块树重建），故不
另起只读投影，也无需页叶那样的隐藏服务后端。栏在分屏右叶是第二实例投影，
本就只读。执行窗是底部工具窗（非视图），
只列块、跑块、看结果，本无编辑控件，入口在文/码面的围栏 ▶ 与码透镜单击块。
状态栏锁图标仍只反映用户锁
（只读面的只读属视图本性，不另挂锁）。只读面上想编辑，一律跳回编辑面
（§6.3）。分屏因此可以没有编辑面（栏×页/览/映、览×映）：此时左 pane 充当
发锚方——栏是只读态活引擎，照常按滚动发锚；览经 §6.3 反向定位发锚——右叶
照 §6.2 分工跟随。

### 6.1 锚与货币：docAnchor 单槽，两层坐标

```
docAnchor = { mdRev, topBlock?, topLine?, cursorLine? }
```

- **两层货币按解析域分工，跨域不做文本换算**（货币换掉的理由是实测：
  2026-11-07 探针验证 text 桥对表格断链——源码行带 `|` 而渲染块文本无；
  纯图段断链——行内图片使段落 textContent 为空；围栏行 `js`、短代码行
  `end` 经包含匹配误命中前文。断点结构性消灭，不靠特判修补）：
  - `blockIndex`（muya 域）：栏/页投影是同一 markdown 的第二 muya
    实例，顶层块序与主引擎天然一致，块序直通，零换算；
  - `line`（1-based 源行号，跨引擎域）：本（CodeMirror）与览/映只认
    行号。md2slides 侧**现成**：渲染 DOM 的块级元素（段落/标题/列表/
    li/表格/tr/引用/HTML 块/围栏/公式）已带 `data-src-start/end`（1 基
    含端点，源自 markdown-it token.map；IR 对应 `block.srcRange`），其
    注释写明的预期消费方即「点击幻灯片跳源码行」——览/映的行号域无需
    新造，只需宿主接线。
- **块首行表**（裁决 3，2026-11-07）：`markdownToState` 顶层块 meta 补
  `startLine`——解析逐行扫描的副产物，同引擎同分块，不引入第二分块标准
  （否决复用 mdcode2run.parse 行号表：它有自己的块界）。表与 mdRev 绑
  定，json-change 防抖后重建一次，滚动/发锚只查表。viewScrollSync 的
  text 桥（resolveSourceLine/findBlockIndex）降级为表脏时的兜底，不再
  是主路径。
- **时效纪律**（两级版本即可）：mdRev → 各面世代号
  （paperProjection 的 rebuildGen、deck 的重建防抖已是此形状）。防抖
  窗口内允许旧态；消费侧校验 mdRev，过期丢弃，不得覆盖新态。

### 6.2 跟随：编辑面 → 览面（裁决 1：分工）

- **连续面跟随滚动**：页、栏投影消费 `topBlock/topLine`——视口顶
  块（含视口内偏移）滚到本面视口顶；投影重建（250ms 防抖
  setContent / replaceChildren）后按锚恢复，废止像素 scrollTop 残值与
  deck 侧 scrollY 数字回放的自保。
- **翻页面跟随光标**：览/映消费 `cursorLine`——放映语义，改哪页跳哪
  页；映跳页、览滚到对应页。行→页映射由现成标注派生，不另造页表：取
  覆盖该行的**最内层**标注元素（区间最小者）**首次出现**的页。不能取
  「每页首个标注」——续页的克隆件（续表/续段/续列表外壳 `cloneNode`
  继承原块标注、重复标题整枚克隆）与首片同值，首个标注会指回上一页；
  跨页块取首片页，片内行区间不细分（留作后续）。
  映全屏/独占下无编辑事件、锚不动，放映不被打扰。
- 跟随是**单向**的；览面自身滚动/翻页不发锚（反向定位见 §6.3；唯一例外：
  无编辑面的分屏里左 pane 充当发锚方，见 §6 头注）。
- 发锚节流：滚动 rAF 合帧、编辑防抖——沿 viewScrollSync 现有形状。
- 幂等消回环：跟随动作目标不变则不动（页号相同 no-op）。「反向定位 →
  编辑面滚动 → 再跟随」链路靠幂等自然收敛，无需回声抑制标记；防抖
  窗口吸收页界换算的 ±1 页抖动。

### 6.3 反向定位与跳转编辑：只读面 → 编辑面

只读面上回到编辑面只有两个动作（裁决 2：双向滚动；2026-11-07 裁决：想编辑
就直接跳转滚动到文/本的相应区域）：

- **反向定位**：以点中处的源行号发锚（origin=reverse，topLine 与
  cursorLine 同置该行）——屏上的编辑面滚到对应块顶部，其余览面按 §6.2
  分工跟随；不切视图、不移焦点。
- **跳转编辑**：以同一行号跳进编辑面——光标落位、焦点移入，可直接开始
  写；编辑面不在屏上则先切过去（目标规则见下）。

| 面                 | 反向定位       | 跳转编辑                   | 取行                                     |
| ------------------ | -------------- | -------------------------- | ---------------------------------------- |
| 栏（活引擎只读态） | 滚动即发锚     | 双击                       | 块序（同实例）                           |
| 栏（分屏右投影）   | 单击           | 双击                       | 块序（同一 markdown 解析，与主引擎一致） |
| 页                 | 单击           | 双击                       | 卡内 `data-src-start`                    |
| 览                 | 单击           | 双击                       | md2slides 现成 `data-src-start`          |
| 映                 | 面板态显式跳页 | 工具条「编辑」按钮         | 当前页首现标注                           |
| 表                 | —（全屏独占）  | 双击                       | 块序（同实例）                           |
| 图（透镜）         | —（全屏独占）  | 双击（同实例，遵栏/表）    | 块序（同实例）                           |
| 码（透镜）         | —（全屏独占）  | 双击（同实例，遵栏/表）    | 块序（同实例）                           |
| 执行窗（工具窗）   | —              | 单击代码块（现行，已合规） | 块的围栏行（mdcode2run 解析，现成）      |

- 码透镜的单击不是跳转编辑而是**工具窗定位**：单击代码块 → 执行窗打开并
  高亮定位该块（`mdcode2run-select-fence` 现成通路）；围栏 ▶ 按钮 → 执行窗
  打开并直接运行该块（`muya:code-run` 现成通路）。两动作仅单视图（文独占 ∨
  码透镜独占）可用。

- 映不复用点与双击：放映器里触屏轻点归翻页，点图归看图浮层（浮层内双击
  是缩放），双击会先连翻两页或落进浮层，故走工具条按钮。览的图片同理：
  点图归看图浮层，对图片想编辑从页卡其余处双击。
- **跳转目标**：编辑面已在屏上（文与只读叶分屏，或执行窗所在的文）→ 就地
  落光标，布局不变。不在屏上（全屏只读叶、只读叶分屏、表/图/码）→ 切到
  **最近显示过的编辑面**（会话内记忆，缺省文）。目标是本：顶级视图切本，
  叶选择挂起不丢。目标是文：清顶级视图；叶选择已含文则保持，否则把左叶
  （全屏即唯一叶）换成文、右叶保留（栏×页 → 文×页、览×映 → 文×映、页 →
  文）；沉浸式放映先退出。
- **光标精度**：同实例（栏/表的活引擎只读态 → 文）落到双击处，块序与块内
  偏移直接可用；跨实例、跨引擎落到该块首行行首，与反向定位同为块级；码沿
  现行落到围栏内容首行。
- **落光标走现成通路**：文侧 `setCursorByOffset({ line, ch })`——执行窗跳文
  （`mdcode2run-reveal-line` → `revealSourceLine`）已在用，保留撤销栈；内部
  整文重建两遍，单次操作可接受，**不进跟随热路径**（跟随靠 §6.1 块首行表）。
  本侧走 CodeMirror 行定位（sourceCode 现成）。docAnchor 行号 1 基，
  CodeMirror 与 setCursorByOffset 0 基，边界处换算。用户只读锁开着时照常
  跳转，锁不变。
- 粒度：**块级**——点中哪块跳哪块（页、览：就近 `[data-src-start]` 祖先的
  起始行，md2slides 现成标注白给）。映（跳页、编辑按钮）与点在页卡空白处
  取该页**首现**标注中起始行最小者（首现 = 同区间未在前页出现，滤掉续页
  克隆件；全为克隆件的续页退到首个标注）——与 §6.2 的首现页规则互为逆
  映射。
- 映的保页从 `startIndex` 裸页号升为**内容锚**（页号随重建增删页而漂
  移，内容锚不漂）：重建后按 cursorLine / 最近一次反向定位行换算页号，
  不存裸页号。

### 6.4 TOC 收口：从监听者矩阵到锚服务收发两端

现行 `scroll-to-header` 监听者矩阵（仅 editor.vue / sourceCode.vue 两处
监听）的碎片化废止——分屏只滚左 pane、页全屏假活（隐藏服务后端容器
rect 全 0）、表/图透镜滚顶（标题 display:none）、览/映无响应、非标题锚
在本视图 no-op，皆因「谁挂载谁响应」：

- **点击 = 发锚**：TOC 条目（标题序）→ 块首行表换算行号 → 广播，各面
  统一响应；
- **高亮 = 读锚**：cursorLine 所在标题节，替代现行 selection-change 光
  标驱动单源——纯滚动浏览时高亮跟随，本/图/览/映面下不再冻结；
- 非标题锚（自定义 `<a id>`）经就近块（→ blockIndex/line）并入同一
  发锚路径，本视图不再是 no-op 特例。

### 6.5 几何时效：晚到资源必须重测

- 页投影：卡内图片 `load` 后 schedule 重测（现只有 fonts.ready）——
  晚到图片改块高会让分页账目漂移，直接威胁 §5 硬验收（屏显页数 =
  printToPDF 页数）；deck 侧 waitForDeckImages 已有，是对照组。
- 锚恢复只在资源就绪后的布局上生效：晚到资源引发的重测 = 新世代号，
  锚在重测后再恢复一次。

### 6.6 落地切片

- **M0 只读收口 + 同实例跳转**：editor.vue 以「用户只读锁 ∨ 只读透镜
  （column / table）」驱动 `setOptions({ readOnly })`（替换现行只监听用户
  锁的 watcher）；栏、表双击跳文（同一实例：按 §6.3 换左叶或清顶级视图，
  解锁后光标落到双击处）。独立于锚服务，可先行。验收：切换不产生
  json-change/脏标记，滚动经透镜切换的锚点恢复复原，用户锁在只读面内外均
  保持，双击后光标落在双击处。
- **M1 锚服务 + 块层**：docAnchor 单槽 + mdRev + 块首行表（muya meta
  补 startLine）；栏投影接入跟随与重建恢复 → 分屏同屏跟随首次成
  立；本↔文/栏切换恢复并入锚服务（viewScrollSync 的 per-tab Map 与
  text 桥主路径退役）；栏右投影的单击定位与双击跳转、栏/表跳本（块序 →
  块首行表 → 行号）随之成立。
- **M2 页投影 + TOC 收口**：fragment 执行器给卡内块/分片标
  `data-src-start`（沿用 md2slides 词汇，1 基，值取块首行表；续片与
  首片同值，取首片页——同 §6.2 规则）；锚→页/卡恢复与图片 load 重测；
  页的单击定位与双击跳转；TOC 改发锚、高亮改读锚 → §6.4 清单整片清零。
- **M3 览/映 locate**：postMessage 协议扩展（`md2s:locate{line}` /
  `md2s:locate-up{line, edit?}`，edit 即跳转编辑；行→页映射与点击取行均
  由现成 `data-src-*` 标注派生，md2slides 不新增 IR）；映工具条加「编辑」
  按钮；映保页换内容锚；反向定位与跳转编辑落地 → 双向滚动成立。
