# 视图模型 v2：文示二支 × 四叶选择

> 状态：**定稿**（2026-11-01）。取代 v1——梯子/语义卡/画廊态/物理徽章/错一位
> 模式/六对枚举/拆除文示等方案均已废弃（§5 一句除名，不展开）。本文只写现行
> 真相，不背修订史；代码与本文不一致时，先改本文。

## 1. 结构：两支四叶

```
 文（编辑态）                示（展示态）
 muya 进程内                 md2slides iframe
 ┌──────┬───────┐          ┌────────┬─────────┐
  page  column            slide    present
  全文   分栏             幻灯片列表   放映
 └──────┴───────┘          └────────┴─────────┘
 空间轴：连续 → 离散         时间轴：全页可见 → 一次一页
 可编辑                      只读（真分页 · 真主题）
```

- **文示的分界 = 引擎边界 = 可编辑性边界**（"借进程不借 DOM"的空间化表达；
  跨组分屏时，分割条就画在引擎边界上）；
- 每支内部一根粒度轴，两轴**正交**——不存在跨支的单一粒度序；
- **表 / 图 / 本**是顶级正交视图（两个内容透镜 + CodeMirror 源码），不进这棵树。

## 2. 选择模型（取代"视图对"枚举）

- 四叶**常驻平铺**在切换器上（默认全部展开，无两级组点击）；
- 点击 = 切换选中，**至多两叶**：
  - 1 叶 → 该视图全屏；
  - 2 叶 → 分屏，左右按按钮序（page < column < slide < present）——
    文左示右、细左粗右由顺序自动成立；
  - 已两叶再点第三叶 → 替换最早选中（FIFO）；不可选到零；
- 表/图/本与四叶互斥：选中顶级视图时叶选择挂起不丢，切回即恢复；
- 选择持久化。

## 3. 分屏交互

- 中间**分割条可拖**，比例记住；**分屏时页宽滑块失效收起**（宽度控制被
  分割条吸收）；
- 单视图滑块回归：page/表/图 = 页宽；present 无；slide = 页缩放（待接线）；
- (slide, present) 两叶皆只读 = 预演/授课导航模式（PPT 缩略图 + 大页的姿态）。

## 4. slide 叶（幻灯片列表）

- md2slides 渲染的**全部真实物理页堆叠**：真分页、真主题、（续）页重复表头；
  放大即原尺寸，非截图缩略图；
- **溢出警告**：物理分页永不产出溢出页（装不下即切（续）页），"溢出"的诚实
  语义 = **一个逻辑页被切成 N 张物理页**——这些页打警告标（首页 `⚠ N页`、
  （续）页描边变色）。数据在 deck 手中（（续）标记 + 每页 src 段），deck 侧
  渲染列表时打标，不需要 muya 侧配合；
- 复用 present 投影面机制（本地服务 + iframe + postMessage + 300ms 防抖重建
  - 重建保页 + 面板态键盘归属）。
