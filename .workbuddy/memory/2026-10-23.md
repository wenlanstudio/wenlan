## mdcols Phase 1 完成：token 预变换 + 白名单

### 关键决策：`processAllTokens` 钩子，而非手动 `lexer()+parser()`

任务书 §3.1 原方案是「把 `html += marked.parse(src)` 换成手动 `lexer()` + 改写 + `parser()`」。**实测证明这条路会静默破坏功能**，已改道：

- marked 的 `parse(src)` 内部是 `preprocess → lexer → processAllTokens → walkTokens → parser → postprocess`。
- 手动 `lexer()+parser()` **跳过 walkTokens**（探针实测 26 次 → 0 次）。muya 的 `walkTokens` 承担三件实质工作：heading 的 `headingStyle`/`marker` 标注、indented code 的 `lang` 清理、**` ```math ` 块整形为 `multiplemath` token（数学渲染核心）**。跳过即静默破坏数学块与标题样式。
- 改用 `marked.use({ hooks: { processAllTokens } })`：位于 lexer 之后、walkTokens 之前，改写 token 即生效，parse 全流程完整保留，**`getHighlightHtml.ts:118` 的 `marked.parse(src)` 一行未改**。
- 实测四项全绿：钩子收到最外层 token 数组；walkTokens 调用次数不变（34=34）；除占位元素外输出与未开启时字节一致；列表项/引用内标记保持 inert。

用户反馈切到 Columns 全白。查出**三个真 bug + 一个连锁问题**：

1. **没调 `muya.init()`**（空白的直接原因）。新引擎要求构造后显式 `init()`（建文档树 + 实例化 UI 插件），`editor.vue` 有调，columnsPreview 漏了 → 文档树根本没渲染。
2. **`getContainer()` 用 `originContainer.replaceWith(newContainer)` 换掉了挂载节点** → `host` ref 仍指向已脱离文档的旧节点；且新节点带 `mu-editor` class。**任何基于 `host.value.querySelector('.mu-editor')` 的查找都返回 null** → 只读与分栏双双静默失效（不报错，最难查的一类）。修法：`muya.init()` 后 `host.value = muya.domNode`。
3. **顶层块在 `.mu-container`（scrollPage），不在 `.mu-editor` 下**。`.mu-editor` 的唯一子元素就是 `.mu-container`；对 `.mu-editor` 跑状态机永远 0 组。`editorEl()` 改为 `muya.domNode.querySelector('.mu-container')`。
4. **连锁**：`setContent` 重建子树后，`revertEditorColumns` 用 WeakMap 里过期的 child 列表 appendChild → 会把已废弃的旧块插回 DOM（重复内容）。已加 `children.every(el => editorEl.contains(el))` 校验，不通过就只清 group/hidden 不还原。

另补样式同步：`.editor-host` 现在镜像 `editor.vue` 的 `.editor-component`（height/overflow/box-sizing/cursor/overflow-anchor）+ `:deep(.mu-container)` 的 `padding-top:20px / padding-bottom:100vh / zoom:var(--editor-zoom,1)`，否则 Page/Columns 观感会漂。

### 顺带修的问题

- **locale**：`commands.columns.*` 之前错放在 `menu.columns` 下（descriptions.ts 引的是 `commands.columns.*`）→ 已移到 `commands.columns`；另外 `view.*`（pageWidth/cursorPosition/readOnly* /pptView/excelView/comingSoon）在 locale 里根本不存在（代码里 `t('view.xxx')` 一直回落成 key 本身）→ 顶层补 `view` 段（en + zh-CN）。**`*.min.json` 才是运行时真加载的文件**（主进程 `common/i18n.ts` 优先读 min），改完必须 `npm run minify-locales`。
- **muya e2e 整个套件跑不起来**：`host/main.ts` 还在 import 已从引擎删除的 `ImageResizeBar` → 模块加载失败，连 smoke 都超时。已移除该 import/use（drag 下 5 个依赖它的 spec 属既有待办）。
